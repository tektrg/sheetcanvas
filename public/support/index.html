ChatGPT plugin

The public plugin opens SheetCanvas in a fullscreen workspace and uses an anonymous session that expires after two hours.

  • Open the workspace before asking ChatGPT to read or change canvas data.
  • Each new public session starts empty. A temporary snapshot restores the same session after a workspace reload; it is not saved into your normal browser workspace.
  • Connected-source tools are not available in the anonymous public plugin.
  • If a session expires, close the workspace and open SheetCanvas again.
  • Keep only one active plugin workspace per ChatGPT session.

Files and canvas data

In the normal app, local CSV and XLSX imports stay in the browser workspace unless you use a connected source. In the public ChatGPT plugin, canvas data is also saved in a temporary session snapshot for reload recovery.

  • Confirm the correct sheet and range before destructive edits.
  • Export important work; the plugin session is not a cloud backup.
  • Refresh only after pending tool calls finish.

Connected data

Connector permissions come from the source system. SheetCanvas cannot grant access your source account does not provide.

  • Reconnect a source if its authorization was revoked.
  • Use read-only access where available.
  • Remove sensitive values from screenshots and support emails.

What to send us

A concise report helps us reproduce the issue without collecting unnecessary data.

  • Browser and ChatGPT or Codex client version.
  • The prompt or action that failed and the visible error.
  • A redacted screenshot when it clarifies the problem.

Privacy and safety

Do not email passwords, API keys, access tokens, or confidential spreadsheet contents. For data handling and deletion requests, read the privacy notice or contact yourfriend@theindie.app.
