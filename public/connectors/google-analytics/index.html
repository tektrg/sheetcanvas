Google Analytics connector

Turn GA4 reports into refreshable SheetCanvas tables.

Use the SheetCanvas Google Analytics connector when GA4 report rows need to sit beside notes, charts, pivots, and other evidence. The app uses OAuth and a backend proxy so refresh tokens are not stored in the browser.

Workflow fit

Best for GA4 analysis that needs context.

The connector imports GA4 Analytics Data API report rows as a SheetCanvas table object. It is useful when traffic metrics need explanation, comparison, or quick visual checks instead of another downloaded CSV.

Good fit

Recurring traffic checks

Run a GA4 report for dimensions like date, sessionSource, or pagePath, then keep the result on the canvas.

Good fit

Canvas-based review

Place analytics rows beside notes, charts, pivots, and sparklines so interpretation stays beside the source table.

Not the goal

GA administration

SheetCanvas reads GA4 report data. It is not an Admin API console and does not manage analytics properties or users.

Setup

Use OAuth through the backend proxy.

The frontend starts Google OAuth with PKCE, then the backend exchanges the code and stores the refresh token encrypted. For local development, start both the Vite app and backend worker before opening the connector dialog.

  • Google Cloud: configure an OAuth client, authorized origin, redirect URI, and enable the Google Analytics Data API plus Admin API.
  • Frontend: set VITE_GOOGLE_CLIENT_ID and, when needed, VITE_BACKEND_URL and VITE_API_BEARER_TOKEN.
  • Backend: set GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, and ENCRYPTION_KEY_B64 for token exchange and encrypted storage.
  • Create the sheet: choose Connect Data, Google Analytics, connect Google, select a property, choose report fields, and import the returned rows.

Report shape

Choose GA4 dimensions, metrics, dates, filters, and ordering.

SheetCanvas sends a structured GA4 Data API report request through the backend and maps the response into table columns and rows.

Dimensions

Start with fields like date, sessionSource, sessionMedium, country, deviceCategory, or pagePath.

Metrics

Use GA4 metrics such as activeUsers, sessions, eventCount, screenPageViews, or engagement metrics.

Controls

Select a preset or custom date range, add optional filters as JSON, and order by a dimension or metric when the report needs sorting.

Refresh

Connected sheets remember the connector, property, and report.

After a successful import, SheetCanvas stores the connector ID, GA4 property ID, report config, refresh timestamp, and truncation state on the sheet.

  • Source stays traceable: the table keeps the connector type, connector ID, property ID, and GA4 report request.
  • Rows stay tabular: the backend returns normalized columns and rows so charts, pivots, sparklines, and notes can use the result.
  • Errors stay visible: failed refreshes keep the prior sheet and store the latest connector error for the UI to surface.

Troubleshooting

Most failures point to OAuth, permissions, or backend config.

Start with Google Cloud settings and backend secrets before changing the canvas. The connector depends on OAuth, encrypted storage, and read access to the selected GA4 property.

  • Connect Google fails: verify VITE_GOOGLE_CLIENT_ID, authorized redirect URI, OAuth consent status, and test-user access.
  • No refresh token: re-consent may be required when Google does not return a refresh token for the account.
  • Properties do not load: confirm the connected Google account has GA4 property access and the Admin API is enabled.
  • Report rejected: check GA4 field names, filter JSON, metric/dimension compatibility, and backend row limits.
