Local files

Start with CSV, XLSX, or XLS imports.

Local file import is the fastest path into SheetCanvas. The imported file becomes a placed table object, so analysis can happen beside the source instead of inside a single expanding grid.

  • Import: open the app and add a CSV, XLSX, or XLS file to create a table object on the canvas.
  • Inspect: sort, filter, and scan the imported table without moving the rest of the workspace.
  • Build from it: create charts, pivots, sparklines, and notes next to the source table.

Object model

Use the canvas to keep evidence and interpretation together.

SheetCanvas treats tables, charts, pivots, sparklines, and notes as workspace objects. This is useful when the analysis has multiple views or caveats that would be hard to track across tabs.

Tables

Use table objects as the source for visual checks and summary views. Local imports and connector queries both create table-shaped data on the canvas.

Connected sheets

Use connectors when the source data should refresh.

Connector-backed sheets keep credentials behind the backend proxy and store a refreshable connector configuration on the sheet.

Available

ClickHouse

Save a ClickHouse connector, run read-only SELECT or WITH queries, and refresh the resulting connected sheet from the canvas. Read the ClickHouse connector guide.

Available with setup

Google Analytics

Connect GA4 through the backend OAuth flow, choose a property and report fields, then create a connected sheet from the returned rows. Read the Google Analytics connector guide.

Backend proxy

Credential handling

Connector credentials and OAuth tokens are stored by the backend, not in the browser. The frontend receives public connector metadata and query results.

Troubleshooting

Check the backend before debugging the canvas.

Most connector failures come from local backend configuration, missing auth values, or a query that exceeds the connector guardrails.

  • Connectors do not load: check VITE_BACKEND_URL, backend availability, and any configured VITE_API_BEARER_TOKEN.
  • ClickHouse query rejected: use a single read-only query starting with SELECT or WITH; write statements are blocked.
  • Google Analytics auth fails: verify the OAuth redirect URL, requested GA4 readonly scope, and backend token exchange settings.
