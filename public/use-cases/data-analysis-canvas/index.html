Data analysis canvas workflow

Analyze spreadsheet-shaped data without hiding the work in tabs.

SheetCanvas is useful when the next question depends on seeing the source table, summary views, and notes at the same time. Bring in a local file or connected sheet, then arrange charts, pivots, sparklines, and written observations around the data you are checking.

Best fit

  • Exploratory analysis: keep source rows, quick summaries, and open questions visible while you investigate.
  • Mixed evidence: place tables, charts, pivots, sparklines, and notes together instead of switching between sheets.
  • Spreadsheet-shaped data: use local CSV/XLSX files or shipped connector outputs when the data naturally fits a table.

How the workflow maps to the app

Build an analysis board from visible SheetCanvas objects.

The app is designed around placed objects. A table can sit beside the chart, pivot, sparkline, or note that explains it, so the canvas stays traceable while the analysis changes.

Start from the source table.

Import a CSV, XLSX, or XLS file, or use a shipped connector to create a table object. Keep that table in view as the evidence for the rest of the canvas.

Add focused summaries.

Create chart, pivot, or sparkline objects for the questions you are answering now, then position each summary near the rows or notes it depends on.

Write down the thinking.

Use notes for assumptions, follow-up questions, and decisions so the canvas captures why a number matters, not only what the number is.

Practical setup

A simple data analysis pass in SheetCanvas

  • Create the table: open SheetCanvas and import a local spreadsheet file or add a connected-sheet result where the shipped connectors fit.
  • Frame the question: add a note for the metric, segment, or anomaly you are trying to understand.
  • Create the checks: add a chart, pivot, or sparkline near the source rows so the summary remains easy to verify.
  • Arrange by evidence: group related objects on the canvas instead of moving each answer into a separate workbook tab.
  • Choose the durable path: keep the canvas for exploration, or use the source BI/database/reporting system when the result needs governed production distribution.

Current boundaries

Use this for visible analysis, not as a replacement for every analytics system.

SheetCanvas is strongest when spreadsheet-shaped data needs a fast workspace for investigation. It does not replace a governed BI platform, database permissions, or scheduled reporting workflow; use it to explore and explain the data around those systems.
