Setup

Connect your agent from the SheetCanvas app.

The connection is separate from data connectors. Data connectors bring data into SheetCanvas; the agent connector lets Claude or Codex operate the canvas.

  1. Open SheetCanvas and choose Connect Agent from the bottom-right control.
  2. Generate an agent connection URL and keep the Expose to agents toggle on while your agent works.
  3. Copy the MCP server URL into Claude Code, Codex, or another MCP-capable client.
  4. Ask the agent to create a table, chart, pivot, note, or dashboard from the data you are analyzing.

Examples

Prompt Claude or Codex for a shareable decision surface.

Claude Code

Use the command copied from SheetCanvas, then ask Claude to summarize a dataset into a chart and decision note.

claude mcp add sheetcanvas --transport http YOUR_MCP_URL

Codex

Add the SheetCanvas MCP URL in your Codex MCP configuration, then ask Codex to build a durable dashboard from the active canvas data.

Business workflow

Ask: "Turn this campaign export into a channel performance dashboard with a pivot, top-line chart, and three decision notes."
