Object model

Tables, visuals, and interpretation stay together.

A SheetCanvas workspace is a surface of spreadsheet objects, not a single expanding tab. That makes it easier to arrange source data, analysis, and notes around the question you are answering.

Drop in local files

Import CSV, XLSX, or XLS files as placed table objects. The table keeps its position on the canvas while you sort, filter, inspect, and build from it.

Create charts and summaries

Turn selected data into bar, line, area, pie, scatter, treemap, pivot, or sparkline objects. Move the result next to the source table instead of losing context.

Write notes near evidence

Add canvas notes for caveats, decisions, and next steps. The note can live beside the table or chart it explains.

When it helps

Use SheetCanvas when spreadsheet work becomes spatial.

The product is strongest when you need to compare multiple views of the same data, preserve context, or build a quick analysis workspace without setting up a BI tool.

  • CSV or XLSX analysis: place imported tables, create visual checks, and keep notes beside the output.
  • Dashboard exploration: arrange charts, pivots, and sparklines around the source tables while you decide what matters.
  • Local-first spreadsheet work: use the canvas without making account setup the first step.

Connected data

Local files first, connectors where they are already part of the app.

SheetCanvas currently includes connector work for Google Analytics and ClickHouse alongside local file imports. This page avoids claiming future integrations as shipped capabilities.

Google Analytics

Use the in-app connector flow for GA4 reporting data when you want analytics tables inside the same canvas as your notes and visual checks. See connector setup.

ClickHouse

Bring ClickHouse query results into the spreadsheet object model for analysis without separating database output from canvas context. Read the ClickHouse connector guide.
