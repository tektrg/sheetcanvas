Setup

Start with the connector, then narrow the report.

SheetCanvas stores the connector identity, GA4 property ID, report configuration, refresh timestamp, and truncation state on the connected sheet so the table can be refreshed later.

1. Connect Google

Use the Google Analytics connector path to authorize access, choose the GA4 property, and confirm the account has permission to read that property.

2. Pick fields

Choose a small set of compatible dimensions and metrics first, such as source, medium, landing page, sessions, active users, and conversions.

3. Import the table

Bring the report into SheetCanvas as rows and columns, then keep the source table visible while you build charts, pivots, sparklines, and notes nearby.

Canvas workflow

Turn the GA4 table into a review surface.

The goal is not to recreate Google Analytics. The useful SheetCanvas pattern is to put the rows beside the interpretation work that normally gets scattered across spreadsheet tabs, screenshots, and meeting notes.

  • Pin the source table: keep the imported GA4 rows near the upper-left of the canvas so every chart and note has visible context.
  • Add one chart per question: chart traffic source mix, landing-page sessions, or conversion movement instead of making one crowded dashboard.
  • Use pivots for comparisons: pivot by source, medium, campaign, page path, or event name when you need quick segment-level review.
  • Write the decision beside the data: place notes next to the chart or pivot they explain, especially when a metric needs follow-up in GA4.

Refresh and limits

Keep refreshable reports focused.

Use a focused report for recurring review, then create a separate connected sheet when the question changes. If a report is rejected, check GA4 field compatibility, filter JSON, OAuth consent, backend connector configuration, and row limits before changing the canvas layout.
