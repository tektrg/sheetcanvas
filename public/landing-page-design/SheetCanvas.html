01 / 09 Start here

First, the basic idea:
it's a canvas, not a grid.

An open surface instead of a tabbed grid. Place tables, charts, pivots and notes anywhere — and work between them.

Mental model

The canvas is a desk. Each table, chart and note is its own object. Move them freely — nothing's locked to a tab.

Interaction

Use it when a spreadsheet feels cramped — too many tabs, too much scrolling, or you need related things in view at once.

02 / 09 Object‑first workflow

To get started,
drag a file onto the window.

CSV, XLSX and XLS work out of the box. The file lands as a table wherever you drop it. Edit it like a normal spreadsheet.

Mental model

The file becomes a movable table. Keep charts and notes alongside it.

Interaction

Drag from Finder. Drop where you want the table.

⌘O or pick a file from disk

03 / 09 Object‑first workflow

The fastest way around
is the command bar.

Press ⌘K anywhere. Type an action, chart or table name. Pick from the list. Faster than the mouse once the canvas fills up.

Mental model

If you can describe it, you can type it. The bar searches actions and objects together.

Interaction

04 / 09 Object‑first workflow

Sorting and filtering
works on each table.

Click a column header to sort or filter. Tables update in place — nearby charts and notes stay aligned with what you see.

Mental model

Filters change what you see, not what's there. Turn one off and the rows return.

Interaction

Click the arrow on a column header, or press F with a column selected. Also in the command bar.

F filter the selected column
column menu multi‑sort numeric · text · date live preview
05 / 09 Object‑first workflow

To make a chart,
select a range and press ⌘E.

A chart object lands on the canvas, linked to the cells you picked. Six types — bar, line, area, pie, scatter, treemap. Switch type anytime from the chart menu.

Mental model

Charts point at their source range. Data changes, chart updates. Keep it near the table.

Interaction

Highlight cells, press ⌘E. Or use the chart button in the table toolbar.

06 / 09 Object‑first workflow

Pivots and sparklines
summarise without hiding.

Need a quick rollup? Make a pivot (⌘⇧P) or inline sparkline (⌘⇧S). Both sit next to the source table — the numbers stay traceable.

Mental model

A pivot is a small read‑only table built from your data. Original rows stay put for double‑checking.

Interaction

Select a table, choose pivot or sparkline. A dialog asks what to group and what to summarise.

⌘⇧P pivot · ⌘⇧S for sparkline
group by sum · avg · count inline spark auto refresh
07 / 09 Object‑first workflow

For comments,
drop a note on the canvas.

Press N to drop a note at the cursor. Write what you noticed, a question, a follow‑up. Leave it next to the chart or table it's about.

Mental model

Notes capture why something looks the way it does. They live on the canvas and travel with the work.

Interaction

Press N, write your note, drag it where it belongs. Markdown works.
